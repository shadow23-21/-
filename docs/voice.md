# 语音输入与男主声音调研

## 已做：语音输入

- 输入框右侧麦克风按钮：中文 `zh-CN`。
- Android 用 `@capacitor-community/speech-recognition` 调系统语音引擎；首次使用会弹系统语音引擎/麦克风授权，属正常一次性流程。
- 浏览器用 Web Speech API 兜底；没有语音服务的设备会提示改用输入法麦克风。
- 语音结果追加到当前输入框，不会覆盖已打的字；发送前自动停止倾听。
- 结果不会自动发送，用户可改完再发。

## 她们一般语音聊天吗？

结论：**语C/同人女的主场是文字，语音是补充/高级功能，不是刚需。**

- 语C 的定义就是“用文字代替要说的话”，通过对语言、动作、心理、环境的描写来演绎；声音扮演是另一条分支（CV/声音 cos），不是语C 本体。[知乎讨论](https://www.zhihu.com/question/290880002)
- 语擦服务同样“主要凭文字描写及对话来模拟角色言行”；近年才延伸出声音扮演，且声音服务通常客单价更高。[南方+](https://static.nfnews.com/content/202608/27/c12760649.html)
- 语C 的主要阵地仍是 QQ/微信文字对戏；语音更多用于“声音扮演/陪聊/哄睡”等细分场景。
- 海外 AI 角色产品把语音当高级功能：Dewy Chat 的语音通话/语音条是“沉浸/付费”变现点，不是基础聊天方式。[Data17](https://www.sgpjbg.com/labelsyh/youxihualiucunyuwebyouxiandafa.html)
- Character.AI 的 Character Calls 是免费附加功能，核心仍是文字角色对话。[TechRadar](https://www.techradar.com/computing/artificial-intelligence/characterai-lets-you-talk-to-your-favorite-synthetic-people-on-the-phone-which-isnt-weird-at-all)
- 星野支持文字/语音/视频多模态，但语音是沉浸能力之一，不是唯一入口。[百度百科](https://baike.baidu.com/item/%E6%98%9F%E9%87%8E/63656793)
- 更大的趋势：传统语音通话在下降，用户更偏文字/异步语音；AI 语音更多是“输入/交互方式”，不是聊天主体。[TechNews](https://technews.tw/ai-agent/study-finds-people-are-talking-less-over-time/5606/)

对我们的意义：

- **不要为了“别人有语音”就上昂贵的 TTS**；我们的优势是便宜。
- 语音输入（免费、系统 ASR）值得做，已经做了。
- 语音回复应作为**可选加价项**：按次扣 1 次或单独语音包，不进 19.9 基础套餐。
- 真要做，先做 4 个预设音色，不做克隆。

## 她们喜欢什么男主声音（公开资料，非我们用户数据）

### 常见偏好

- **低音炮 / 苏**：低声、慢速、尾音压下去，叫昵称/“姐姐”时尤其戳。
- **温润克制**：不油腻、不播音腔，清亮内敛、轻微鼻音、普通话标准。
- **少年感**：干净、轻、有一点莽撞；和低音炮是两种不同人群。
- **矜贵/有钱感**：不是老成，是松弛、年轻、被教养过的声音。
- **高冷禁欲**：话少、句子短、情绪压在字下面。

## 推荐给鲸忆的声线

不要做一个“通用男声”，做 4 个预设：

1. **克制低音**：默认；低、慢、尾音收，适合医生/年上/高冷。
2. **温润**：中低音、气声少、普通话干净，适合温柔/竹马。
3. **少年**：偏亮、轻、语速稍快，适合年下/校园。
4. **矜贵**：松弛、年轻、咬字干净，适合财阀/少爷。

每个角色创建时选一个默认声线；后续可换。不要默认“霸道总裁播音腔”。

## 语音回复（TTS）可行性

**可以做，但先不做。**

### 技术路径

```
文字回复 → gateway /api/tts → TTS 供应商 → 音频 URL/流 → App 播放
```

可选供应商：

- 阿里 CosyVoice / Qwen3-TTS：中文、情感、双向流式，适合边生成边播。
- MiniMax 语音：中文自然度好，有情感/角色音色。
- ElevenLabs：海外音色库强，中文也可；成本较高。
- 火山/讯飞：国内合规和稳定性好，但接入和审核更重。

来源：[八大 TTS 厂商梳理](https://charlesliucn.github.io/2025/2025-10-22-tts-companies/)

### 成本/体验

- 一条 100–200 字回复，TTS 成本大约几分钱到一毛多（随供应商/音色变化）。
- 流式 TTS 可以把首包延迟压到 1–3 秒；非流式要等整段。
- 需要缓存：同一句话不重复合成。
- 需要播放控制：暂停/继续/倍速/耳机。
- 托管额度模式可以按“语音回复”额外扣 1 次或加价。

### 风险

- **声音克隆版权**：不要克隆真实配音演员/真人声音；只用有授权的预设音色。
- **角色 IP**：不要把“某乙游男主同款音色”作为卖点；只做“低音/温润/少年/矜贵”这种风格。
- **内容审核**：语音也要过文本审核；不能生成违规内容。
- **隐私**：录音/文本发送给 TTS 供应商，需要隐私政策说明。
- **包体/性能**：云端 TTS 不增加包体；本地 TTS 会增加几十 MB。

### 建议

1. 先把语音输入跑顺（已做）。
2. 下一版做 **4 个预设音色 + 每角色默认声线**，不做克隆。
3. 用 gateway 代理 TTS，key 不进客户端；按次扣额度。
4. 先给 10 个用户试用，看“听语音”是否真的提高留存/付费，再决定要不要全量。
