# 冷启动与宣传

目标：先让 100 个真实同人女用上，再谈上架。

## 一句话定位

**“DeepSeek 限额后，把聊了几个月的电子男友搬进手机；他记得你们的事，人设不崩，19.9 一个月。”**

不要宣传“无审查/无限量/成人内容”；这三类会把渠道和支付都做死。

## 先打哪群人

1. **被 DeepSeek 限额逼疯的语C/梦女**：已经在用 DeepSeek 聊几个月，有几十万字记录，最痛。
2. **角色卡/酒馆用户**：有 JSON/聊天记录，习惯导入。
3. **乙游/同人女**：有固定男主，想要“只属于我”的长期陪伴。
4. **AI 工具尝鲜者**：愿意试新 App，但不是核心。

## 渠道优先级

### 1. 小红书（主战场）

同人女密度最高，适合“故事型”笔记，不适合硬广。

内容模板：

- 「DeepSeek 限额后，我把聊了三个月的沈砚搬进了手机」
- 「导入 30 万字聊天记录，他居然还记得上次伞骨上的雨珠」
- 「角色崩了怎么办？我把人设/关系/边界/语气样本都写进去了」
- 「19.9 一个月，每天 100 条，够我和他聊了」
- 「不卖 API key，输入兑换码就能聊」

发布节奏：

- 每周 3–5 篇，图片用真实聊天截图（打码）。
- 评论区不要放下载链接，引导“主页/店铺”。
- 用“求码/蹲一个”做互动，私信发体验码。
- 重点关键词：DeepSeek、语C、梦女、同人女、AI男友、角色扮演、长期记忆。

### 2. QQ 群 / 微信群（种子用户）

- 加 10–20 个语C/同人/DeepSeek 用户群，不要一进群发广告。
- 先聊“DeepSeek 限额”痛点，再私聊愿意试的人。
- 给 20–50 个 **300 次体验码**，换真实反馈和截图。
- 建自己的用户群，收集“最想要的功能/最崩的一次”。

### 3. Lofter / 微博 / B站

- Lofter：长文教程「怎么把 DeepSeek 记录导入鲸忆」。
- 微博：超话/语C话题下发“记忆测试”截图。
- B站：1–3 分钟录屏「导入 → 重建人设 → 问他还记不记得」。
- 不要做硬广，做“教程/实测”。

### 4. 贴吧 / 豆瓣小组 / 半次元

- 只发经验帖，不发下载链接；签名/主页引流。
- 适合找“角色卡/语C/乙女”核心用户。

### 5. KOC / 小博主

- 找 1k–5w 粉的语C/乙女/AI 工具博主。
- 给免费 3000 次码 + 20%–30% 分成/返现。
- 要求真实体验，不要求吹；差评也要能改产品。

## 产品内增长

- 首次导入后，引导问一句「你还记得……吗？」，让用户自己看到记忆。
- 送 100–300 次体验码，用完再卖月包。
- 付费用户送 1 个邀请码（双方各得 300 次），先手工发。
- 导出功能做好：用户敢进来，也敢走，反而更愿意付费。
- 微店商品页放：能做什么、不能做什么、19.9 包含多少、到期规则。

## 30 天冷启动计划

### 第 1 周：20 个种子

- 找 20 个被 DeepSeek 限额的用户，免费给 3000 次。
- 帮她们导入、跑通“记忆测试”。
- 收集 5 个真实截图/反馈。
- 发 3 篇小红书。

### 第 2 周：50 个用户

- 找 2–3 个 KOC 试用。
- 发 5 篇笔记 + 1 条 B 站录屏。
- 建 QQ 群，收集需求。
- 目标：50 个激活用户，D7 留存 > 20%。

### 第 3 周：付费验证

- 上微店标准月包 19.9。
- 给活跃用户发 9.9 轻量月包优惠。
- 目标：10 个付费用户；算真实 API 成本/毛利。
- 观察退款/投诉/“额度不够”的比例。

### 第 4 周：决定是否放大

- 如果 D7 > 25%、付费转化 > 3%、毛利 > 55%，继续投 KOC/小红书。
- 如果激活低，改导入/首次体验；如果留存低，改记忆/人设；如果付费低，改定价/包装。
- 不要先买量；先修产品。

## 关键指标

- 激活率：导入成功 + 发出第一条消息 / 下载
- D1 / D7 留存
- 日均消息数
- 付费转化率
- 每个付费用户 API 成本
- 退款/投诉率
- “额度不够”反馈占比

## 什么时候上架

- 至少 500–1000 个真实用户，D7 > 25%，付费转化 > 3%，再考虑 Google Play。
- 国内商店需要公司/软著/备案，别在产品没验证前烧钱。
- 上架前补：举报/屏蔽、年龄门、未成年人模式、隐私政策、内容审核。

## 不要做的事

- 不要宣传“无审查/无限量/成人内容”。
- 不要卖 API key。
- 不要一上来投信息流广告。
- 不要用“永久免费”拉人，后面再收费。
- 不要忽视退款和“额度不够”的用户，她们会在同人圈里说。
