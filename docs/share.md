# 怎么把鲸忆分享出去

## 前提

- 正式分发包必须是 **签名 release APK**，不要发 debug 包。
- 必须先把 gateway 部署到公网 HTTPS，并用 `-GatewayUrl` 重新构建；否则别人装了也兑换不了。
- iOS 暂时没有；只发安卓。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1 -GatewayUrl https://你的域名
```

产物：`release/whale-memory-1.0.0.apk`。

## 上传到哪里

- **蓝奏云 / 123 云盘 / 夸克网盘**：放 APK，设置提取码。
- **QQ 群文件**：最稳，适合种子用户。
- **不要直接在微信里发 APK**：容易被拦；发网盘链接/二维码。
- 小红书不要直接放 APK 链接，引导到闲鱼/私信/主页。

## 安装步骤（发给用户）

1. 安卓手机打开网盘链接，下载 APK。
2. 点安装，系统提示「未知来源」→ 允许本次安装。
3. 打开「鲸忆」，到设置输入兑换码。
4. 如果想导入旧记录：角色页 → 导入新角色 → 选 DeepSeek 导出的 zip。
5. 想导出：角色页 → 导出全部 → 保存/分享 ZIP。

## 闲鱼卖码

- 闲鱼搜索词：**鲸忆鲸忆**。
- 商品标题：`鲸忆 月包 兑换码 自动发货 角色记忆 安卓`
- 商品说明写清楚：
  - 9.9 轻量月包：1200 次 / 30 天
  - 19.9 标准月包：3000 次 / 30 天
  - 29.9 畅聊月包：5000 次 / 30 天
  - 兑换码一次性，月包 30 天有效
  - 不卖 API key，不需要自己找 API
- 自动发货：把码作为卡密上传，一单一码。
- 前 10 个体验名额：发 9.9 月包码，要求真实反馈/截图（可选）。

## 二维码/落地页

没有官网也能做：

1. 用「草料二维码」把网盘链接生成二维码。
2. 小红书/QQ群发二维码图片，配一句「安卓扫码安装」。
3. 以后有域名再做落地页：下载按钮 + 安装教程 + 闲鱼/微店入口 + 隐私政策。

## 分享话术

- 「不用找 API，兑换码直接聊；能导入 DeepSeek 记录，也能一键导出。」
- 「前 10 个送 9.9 月包体验，安卓扫码装。」
- 「人设/关系/边界/语气都能写，角色不容易崩。」
- 「数据在本机，想走随时导出。」

## 不要做

- 不要发 debug 包。
- 不要发自己的 API key。
- 不要宣传「无限量/无审查/成人内容」。
- 不要在没部署公网 gateway 前卖给陌生人。
- 不要承诺 100% 不崩人设；说「人设锚点 + 出戏自动重写」。
