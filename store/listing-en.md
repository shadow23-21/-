## Full description

Whale Memory is a local-first long-term memory app for text roleplay.

Import a DeepSeek export (`.zip`, `.json`, `.jsonl`, or plain text), and the app rebuilds the character's persona, relationship, timeline, long-term memories, and speaking style. The character can then continue from a new chat without forgetting the story.

Highlights:

- Import DeepSeek / ChatGPT / SillyTavern / plain-text conversations
- Rebuild a story bible: persona, relationship, address terms, boundaries, timeline, voice samples
- Long-term memory with BM25 retrieval; only relevant memories are injected each turn
- Multiple characters, each with isolated memory and messages
- Search, sort, rename, export, and import character packs
- Create a blank character from scratch
- Tap “Remember” on any message to pin it to long-term memory
- Local-first: chats and characters live in on-device IndexedDB; API keys stay on device
- BYOK: use your own DeepSeek / Zhipu API key; we do not run a model service

For fan fiction, text roleplay, character-card players, and long-running character companions.

Note: the app does not provide model inference. Replies come from the third-party API you configure. AI-generated content may be inaccurate; 18+ recommended.
