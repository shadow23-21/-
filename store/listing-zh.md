## 完整说明

鲸忆是一个本地优先的长期角色扮演记忆应用。

你可以把 DeepSeek 官方导出的聊天记录直接导入（支持 `.zip`，自动读取 `conversation.json`），它会整理出角色人设、关系、时间线、长期记忆和语气样本，让角色在新对话里继续记得你们的事。

主要功能：

- 一键导入 DeepSeek 官方导出 / JSON / JSONL / 纯文本
- 自动生成 story bible：人设、关系、称呼、边界、时间线、语气样本
- 长期记忆 + BM25 检索，每轮只带相关往事，省 token
- 多角色：每个角色独立记忆和消息，可搜索、排序、改名、导出角色包
- 新建空白角色：不导入也能直接设定人设开聊
- 消息「记住」：手动把一句话写进长期记忆
- 本地优先：聊天记录和角色数据存在设备 IndexedDB；API Key 只在本机
- 自带 Key（BYOK）：使用你自己的 DeepSeek / 智谱 API Key，不经过我们的服务器

适合：同人创作、语C、长期角色陪伴、角色卡玩家。

说明：本应用不提供模型服务，AI 回复由你配置的第三方 API 生成；请遵守对应服务商条款。应用内生成内容请自行判断，未成年人请勿使用。
