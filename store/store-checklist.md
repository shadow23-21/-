# 上架清单

## 0. 先补产品硬缺口

- [x] **DeepSeek 直连**：release 已默认 `VITE_DIRECT_DEEPSEEK=true`，用户填自己的 key 即可聊，不依赖 gateway。
- [ ] **可选：公网 HTTPS gateway**：如果要支持智谱 / 服务端 key / 用量统计，把 gateway 部署到 HTTPS（Cloudflare Worker / 轻量 VPS），App 的 `VITE_API_BASE` 改成它。
- [ ] **内容安全**：举报、屏蔽角色、敏感词/图片过滤、未成年人模式/年龄门。商店和国内监管都会查。
- [ ] **隐私政策公网 URL**：填 `privacy-policy.md` 的运营者/邮箱，托管到 GitHub Pages 或自己的域名。
- [ ] **账号/数据删除**：当前无账号；至少提供「删除角色/清除数据」，商店要求可删除。
- [ ] **AI 标识**：聊天页标注“AI 生成”，符合生成式 AI 标识要求。

## 1. 直接分发 APK（最快）

- 文件：`release/whale-memory-1.0.0.apk`
- 校验：`SHA256SUMS.txt`
- 渠道：官网/落地页、QQ 群、小红书、B 站简介
- 注意：Android 未知来源安装；iOS 不能这样装。
- 签名密钥：`release/keystore-backup/`，务必备份；丢了无法更新。

## 2. Google Play（海外，推荐先走）

费用：$25 一次性；新个人开发者通常要求 12 名测试者 × 14 天封闭测试。

- [ ] 开发者账号 + 身份验证
- [ ] 上传 `release/whale-memory-1.0.0.aab`（package `com.whalememory.app`，versionCode 1）
- [ ] 商店资料：`listing-en.md` / `listing-zh.md`、`icon-512.png`、`feature-graphic.png`、`screenshots/`
- [ ] 隐私政策 URL
- [ ] Data safety 表单：说明聊天内容会发送给用户自选的第三方模型；本地存储；不收集账号
- [ ] 内容分级问卷：AI 生成内容、用户生成角色、可能含成人主题 → 17+
- [ ] 目标受众：18+
- [ ] 广告：无
- [ ] AI 生成内容政策：提供举报/屏蔽，说明内容由第三方模型生成

## 3. Apple App Store（海外）

费用：$99/年；需要 Mac + Xcode 或云 Mac。

- [ ] App Store Connect 新建 App，Bundle ID `com.whalememory.app`
- [ ] TestFlight 先发（最多 10,000 测试者，90 天）
- [ ] 隐私营养标签：本地数据、API Key、第三方模型请求
- [ ] 年龄分级 17+；UGC/AI 内容需要举报/屏蔽/过滤
- [ ] 审核可能引用 1.2（UGC）、4.2（最低功能）、5.1.1（权限）
- [ ] 中国大陆区：需要 AIGC 备案 + 安全评估，个人基本不可行

## 4. 中国大陆安卓商店

需要公司主体，个人开发者基本走不通。常见材料：

- [ ] 软件著作权（软著）
- [ ] ICP 备案 / 公安联网备案
- [ ] 生成式 AI 服务备案/登记
- [ ] 算法备案
- [ ] 安全评估（《人工智能拟人化互动服务管理暂行办法》要求上线前完成）
- [ ] 未成年人模式、年龄门、2 小时提醒
- [ ] 内容审核（涉黄/涉政/自残/情感操纵等红线）
- [ ] 应用商店资质审核（应用宝/华为/小米/OPPO/vivo）

## 5. 合规红线

- 《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行）：安全评估、算法备案、未成年人保护、不得诱导情感依赖/沉迷。
- 生成式 AI 内容标识：AI 生成内容要标识。
- 不得生成淫秽色情、暴力、自残自杀鼓励等内容；托管涉黄有刑事风险。
- 同人角色卡涉及第三方 IP 版权：只做用户自导入，不做官方卡市场。

## 6. 现实建议

1. 先发**签名 APK + 落地页**，验证有人愿意装、愿意付费。
2. 再上 **Google Play 海外**，用中文/英文 listing 吃海外华人 + 国内翻墙用户。
3. 大陆 iOS/安卓商店等有公司主体、预算、合规团队再做；不要先买量。
